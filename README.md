# Gold Loan Manager

A Windows desktop application developed as a B.Tech major project to simplify and manage gold loan operations in jewellery firms.

The application is a redevelopment of a subscription-based gold loan management system, with the goal of making daily operations easier and more organized.

## Features

- **Customer Management** – Maintain customer details and KYC information.
- **Gold Valuation** – Calculate gold value based on weight and purity.
- **Loan Management** – Create and manage gold loan records.
- **EMI Management** – Generate EMI schedules and track repayments.
- **Penalty Calculation** – Manage overdue payment penalties.
- **Loan Transfer** – Handle loan transfer operations.
- **Reports & Receipts** – Generate reports and PDF receipts.
- **User Roles** – Separate access for Admin and Staff.

## Technology Stack

- Electron.js
- React.js
- Node.js

## Running the Application

1. Download or clone this repository.
2. Extract the application files if downloaded as an archive.
3. Locate the main Gold Loan Manager executable, if included.
4. Run it on a supported Windows system.

**Note:** The repository currently exposes runtime files rather than the complete development source code. The main application executable should also be included in the distribution for users to launch it.
